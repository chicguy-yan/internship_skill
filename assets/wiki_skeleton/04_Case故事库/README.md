# 04 Case 故事库

可口述的 2-3 分钟故事。每个 case 既是面试素材，也是个人成长沉淀。

## 两类故事

- **困难闭环型**：我推动了一件大家都觉得难推的事
- **认知反转型**：我一开始判断错了，后来通过证据改变策略

## 命名约定

`case_<类型>_<2-4字关键词>.md`

例：
- `case_困难闭环_长记忆方案落地.md`
- `case_认知反转_角色一致性方向调整.md`

## 写法

每个 case 包含：
1. 1 句话摘要（30 字以内）
2. 完整故事（书面版）
3. 口述版（2-3 分钟，预排练用）
4. 高频追问预案表

字段与公式参考 `references/case_storybook.md`。

## 升级路径

case 通常**不直接写出来**，而是从其他层"升级"：
- 02 决策记录里某条决策有显著结果 → 升级为困难闭环 case
- 项目过程中你的判断翻盘过 → 升级为认知反转 case
- Daily Workflow 标记为 [候选 case] 的事件 → 数据回归后升级

## 数量目标

整段实习准备 **2-3 个 case**（按用户的[实习框架](../../实习框架) Step 3 要求），不贪多。
