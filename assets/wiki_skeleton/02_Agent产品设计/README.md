# 02 Agent 产品设计

记录产品形态、核心链路、关键决策、Eval、商业化。**这一层是面试主战场**——产品 sense 和决策能力都在这里展示。

## 条目

- 产品形态.md — 主要交互形态、玩法层级、付费触点
- 核心链路.md — 用户输入到输出的完整链路与每个节点的设计决策
- 决策记录.md — 每条产品决策的备选方案、取舍维度、最终选择、结果
- Prompt设计.md — system prompt 框架、约束词、few-shot 策略（视项目情况选填）
- Eval框架.md — 自动 + 人工 eval 体系，评测如何反哺迭代
- 商业模式.md — 收入构成、付费漏斗、价格分层

## 填法

每个条目的字段定义参考 `references/product_design.md`。

## 更新触发

- 需求评审 / PRD / 产品方案
- 关键决策（方案对比、灰度结论、AB 结果）
- Prompt 大版本调整
- 新 eval 指标上线
