# 01 行业认知

记录业务在 C 端对话/陪伴/创作 Agent 行业里的位置：赛道、竞品、用户、北极星指标、政策风险。

## 条目

- 业务背景.md — 项目在 BU 的战略定位、团队 OKR、你负责的方向
- 北极星指标.md — DAU/留存/付费等核心指标 + 当前值与目标
- 竞品地图.md — 主要竞品差异化矩阵
- 用户画像.md — 典型用户类型 + 诉求 + 流失原因
- 行业关键词.md — 业务/技术黑话 → 通俗含义对照
- 政策与伦理风险.md — 合规要求、未保、伦理边界

## 填法

每个条目的字段定义参考 `references/industry_C_agent.md`。
