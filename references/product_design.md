# 02 Agent 产品设计层模板

## 适用场景

记录产品形态、核心链路、关键决策、Eval、商业化等"产品视角"的内容。

## 必备条目清单

### 产品形态.md

字段：
- 主要交互形态（聊天界面 / 卡片流 / 信件 / 朋友圈 / RPG 场景）
- 角色系统（官方 IP / UGC / 用户自定义 / 演化）
- 玩法层级（自由聊 / 剧情任务 / 养成 / PVP / 创作）
- 多模态能力（文字 / 语音 / 图片 / 视频 / 表情）
- 社交属性（私聊 / 群聊 / 分享 / 关注）
- 付费触点（订阅墙 / 增值能力 / 限时活动 / 虚拟道具）

### 核心链路.md

记录"用户输入 → 最终输出"的完整链路，每个节点写一段：

```
用户输入
  ↓
意图识别 / 输入预处理
  ↓
Prompt 构造（含人设 / 历史 / RAG / 约束）
  ↓
模型推理（哪个模型 / 流式 / 工具调用）
  ↓
后处理（安全过滤 / 风格化 / 分段 / 表情插入）
  ↓
输出渲染
  ↓
反馈采集（点赞 / 重新生成 / 时长 / 留存）
```

每节点详细写：
- 这一步做什么
- 关键设计决策（为什么这么做）
- 当前性能/质量瓶颈
- 关联的 02_Agent产品设计 / 03_前后端研发 条目（双链）

### 决策记录.md

每条决策一个表格（精简版，详情可拆条目）：

| 字段 | 内容 |
|---|---|
| 日期 | 2026-MM-DD |
| 决策点 | 一句话描述 |
| 备选方案 | 方案 A / B / C |
| 取舍维度 | 用户体验 / 成本 / 工程难度 / 数据风险 |
| 最终选择 | B |
| 理由 | 三点核心原因 |
| 验证方式 | AB / 灰度 / 用户访谈 |
| 结果 | 数据 + 一句结论（如果还没结果就标"观察中"） |
| 涉及人 | PM/算法/前端/后端 |

**注意**：决策记录是 case 故事的"原料"。当某条决策有显著结果（成功/失败/反转）时，可以升级到 04 层 Case。

### Prompt 设计.md（视项目情况选填）

- system prompt 的总体框架（人设 / 风格 / 安全 / 工具）
- 关键约束词的来源和效果
- few-shot 例子的选取标准
- 模板变量和动态注入逻辑
- 已知失败模式（破甲 / 漂移 / 重复）和缓解

### Eval 框架.md

- 自动 Eval（指标 + 工具 + 频率）
- 人工 Eval（评测人 / rubric / 抽样策略）
- 离线 vs 在线 Eval
- 关键 KPI 的拆解
- Eval 结果的反哺路径（怎么影响下次迭代）

### 商业模式.md

- 收入构成（订阅 / 增值 / 广告 / 平台分成）
- 关键转化漏斗（曝光 → 试用 → 触发付费墙 → 付费 → 续费）
- 价格分层与权益对照
- 付费驱动设计（爆点功能 / 稀缺性 / 情感价值）

## 填写约束

- **决策必有理由**：备选方案、取舍维度、最终选择三者缺一不可
- **链路图保鲜**：核心链路改动时要同步改条目，不要让线上和文档脱节
- **Eval 数字带时间戳**：所有指标值标日期，过期的留历史
