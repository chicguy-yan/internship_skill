# 01 行业认知层模板（C 端对话/陪伴/创作 Agent）

## 适用场景

业务领域是 C 端对话/陪伴/创作类 Agent 产品（如：AI 角色聊天、AI 男/女友、AI 创作助手、AI RPG、AI 剧本杀等）。

## 必备条目清单

每个条目对应 `01_行业认知/` 下的一个 md 文件。

### 业务背景.md

- 项目所在 BU 的战略定位（增量 / 留存 / 商业化 / 降本 / 生态建设）
- 团队 OKR（或短/中/长期目标拆解）
- 当前季度最重要的一件事 + 为什么
- 你（用户）在团队里负责的方向
- 上下游：你交付给谁，谁依赖你

字段示例：
```
- BU 战略：增量（拉新 + 留存）
- 季度目标：D7 留存提升至 X%
- 我负责：人设记忆系统的产品+前端
- 上下游：上游=算法/Prompt 团队，下游=客户端/服务端
```

### 北极星指标.md

C 端对话陪伴类常见北极星：
- DAU / MAU
- 人均日对话轮次（活跃度）
- D1 / D7 / D30 留存
- 首日 / 首周 付费转化率
- ARPU / LTV
- 平均会话时长

记录格式：
```
| 指标 | 当前值 | 目标值 | 来源/口径 |
|---|---|---|---|
| D7 留存 | 35% | 40% | 数据看板 xxx |
```

### 竞品地图.md

差异化矩阵字段（每个竞品一行）：

| 维度 | 含义 |
|---|---|
| 产品形态 | 纯聊天 / 卡牌 / RPG / 多模态 / 工具 |
| 人设系统 | 预设角色 / 自定义 / UGC / IP 联动 |
| 记忆能力 | 短期 / 长期 / 情节 / 用户画像 |
| 多模态 | 图片 / 语音 / 视频 / 表情包 |
| 玩法机制 | 自由聊天 / 任务 / 剧情 / 养成 |
| 付费模式 | 订阅 / 虚拟物品 / 增值服务 / 免费 |
| 用户规模 | DAU 量级 |
| 我们差异 | 一句话写我们与之的差异化点 |

国内常见对标：星野、Talkie、猫箱、X Eva、Glow、筑梦岛、Wow 等
海外常见对标：Character.AI、Replika、Chai、Janitor AI、Linky 等

### 用户画像.md

至少分 3 类典型用户，每类写：
- 人口学：年龄段、性别、职业、地域
- 使用场景：陪伴 / 情感倾诉 / 创作 / 工具 / 娱乐 / RPG
- 核心诉求：要什么（情感价值 / 角色一致 / 高质量生成 / 隐私 / 玩法）
- 付费意愿来源：什么时候愿意付钱
- 流失原因：什么会让他们走

### 行业关键词.md

把团队/PM/技术常说的术语和它们的具体含义记下来（去黑话化）：

| 关键词 | 通俗含义 | 在我们项目中的具体体现 |
|---|---|---|
| 角色一致性 | Agent 不要崩人设 | 我们用 system prompt + 检索约束保证 |
| 长期记忆 | 跨会话记得用户/剧情 | 我们用 vector DB + 摘要压缩 |
| 安全合规 | 不输出有害内容 | 接入 xxx 安全网关 + 二次过滤 |
| RAG | 检索增强生成 | 用于人设知识/世界观固定 |

### 政策与伦理风险.md

- 内容审查相关法规（国内 + 海外）
- 未成年保护
- 拟人化伦理（虚假承诺/过度依赖）
- 数据隐私（用户对话数据如何处理）
- 知识产权（IP 联动 / UGC 二创）

## 填写约束

- **不要造数据**：竞品 DAU 写不出准确值就写区间或留空
- **来源标注**：每个数据点附 `来源：xxx 看板/竞品官网/QuestMobile 报告`
- **及时性**：每条注明 `更新于 YYYY-MM`，超过 3 个月提醒复核
